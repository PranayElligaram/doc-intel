# The corpus definition. One Companies House company number per line;
# everything after a # is a comment.
#
# This file is committed on purpose. The alternative - searching the API at
# fetch time - gives a different corpus to every person who runs it on every
# day they run it, and a corpus that cannot be reproduced cannot support a
# number in the README.
#
# SELECTION RATIONALE
# A representative draw from Companies House is almost entirely micro-entities
# filing abridged accounts that omit turnover, auditor and employee count. That
# would make the gold set nearly all not_stated: plenty of abstention cases,
# almost nothing testing extraction, and no way to tell a model that abstains
# correctly from a model that extracts nothing. So the list is stratified and
# deliberately top-heavy - roughly two thirds full audited accounts, one third
# small and audit-exempt. The not_stated cases should be genuine and a
# minority.
#
#   large listed PLC   full statutory accounts, audited, turnover and profit
#                      before tax stated in millions or thousands under a scale
#                      headline. Exercises the hard fields and the Scale
#                      normalisation path. Also the tier least likely to be a
#                      scan, which keeps the text-layer distribution readable.
#   mid-size private   full accounts, audited, plain typesetting rather than a
#                      designed annual report. Extraction without the visual
#                      scaffolding.
#   small company      abridged. Turnover often absent, employee count usually
#                      present. Mixed cases.
#   audit-exempt       no auditor exists to name. The cleanest not_stated we
#                      have: truthfully absent, not missed.
#
# PROVENANCE
# These numbers were collected by hand from
# find-and-update.company-information.service.gov.uk in August 2026.
#
# Tiers are NOT yet assigned. The fetcher records each filing's accounts type
# from the filing history, so the tier for every number below comes from the
# manifest after the first live fetch rather than from a reading of a web page.
# Until that is done, the stratification described above is the intent, not a
# statement about this list.
#
# The first fetch is only a partial check on the numbers themselves: a
# transposed digit usually resolves to a real but different company rather than
# a 404, so the company names in the manifest are worth a glance before the
# corpus is trusted.
