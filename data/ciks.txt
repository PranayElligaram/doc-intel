# The corpus definition. One SEC EDGAR CIK per line; everything after a # is a
# comment. Leading zeros are optional - the fetcher pads to ten digits.
#
# This file is committed on purpose. The alternative - searching the API at
# fetch time - gives a different corpus to every person who runs it on every
# day they run it, and a corpus that cannot be reproduced cannot support a
# number in the README.
#
# WHAT WAS VERIFIED, AND BY WHAT
# Every CIK below was resolved through https://www.sec.gov/files/company_tickers.json
# and then checked against its own submissions JSON on 2026-08-23. For all 18:
# the CIK resolves to the named company, and at least two 10-K filings are
# reachable with a non-empty primaryDocument. The 10-K counts in the tier notes
# below are counts from that check, not estimates.
#
# What is NOT verified is the tier label itself. "Mid-cap" and "pre-revenue"
# are my editorial judgement about what each filer contributes to the corpus.
# The first fetch will not confirm or refute them; only reading the filings
# will.
#
# SELECTION RATIONALE
# A representative draw from EDGAR is mostly small filers and shell companies,
# and a corpus of those would test almost nothing. So the list is stratified
# across the properties that actually make extraction hard - document size,
# table density, filename convention, and whether a field is genuinely absent.
#
# One trap this list is built to include on purpose: the large banks. Their
# 10-K does not appear in the submissions JSON's `filings.recent` block at all,
# because they file thousands of pricing supplements a year and push their own
# annual report out of that window. Any fetcher that reads only `recent` gets
# one 10-K from them instead of two and never notices. See the overflow walk in
# docintel/ingest/edgar.py.

# --- mega-cap tech ---------------------------------------------------------
# Large inline-XBRL filings from the major filing platforms, the densest
# tagging in the corpus. Apple is also the filename-convention case: its own
# 10-Ks use aapl-20250927.htm, a10-k20189292018.htm and d17062d10k.htm.

0000789019   # Microsoft Corp         7 10-Ks in recent
